Instructions: 
1. Cloner le dépôt : git clone https://github.com/scarglla/ynov-scaringella-matteo.git
2. Ouvrir le dossier du projet dans un terminal.
3. Installer les dépendances avec la commande : npm install
4. Lancer le serveur de développement avec la commande : npm run dev
5. Ouvrir le lien local indiqué dans le terminal (généralement http://localhost:5173/) dans un navigateur web.
